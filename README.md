# codecalculator-privacy

Hosts the Microsoft Store privacy policy page for **Code Calculator** via GitHub Pages.

Source of truth for the policy text is `CodeCalculator/store/PrivacyPolicy.md` in the main project folder; `index.html` here is the published, styled copy. When the policy changes, update both.

Live at: https://okio-mm.github.io/codecalculator-privacy/
